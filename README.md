# Quest To-do

할 일을 완료하면 포인트를 받고, 모은 포인트로 가상 기프티콘을 교환하는 게임형 할 일 관리 웹앱입니다.

HTML · CSS · 순수 JavaScript만 사용합니다. 프레임워크, 빌드 도구, 외부 라이브러리, 서버, 외부 폰트가 없습니다.

## 실행 방법

`index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다. 설치나 빌드는 필요 없습니다.

- Chrome 또는 Edge를 권장합니다.
- Firefox는 설정에 따라 `file://`로 연 페이지에서 저장이 되지 않을 수 있습니다.

## 기능

### 할 일
- 제목(앞뒤 공백 제거 후 1~50자)과 카테고리(업무 / 개인 / 공부)로 추가합니다. Enter 키로도 추가됩니다.
- 체크박스로 완료하고 해제합니다. 완료한 항목은 취소선이 그어지고 목록 아래로 내려갑니다.
- 수정 버튼을 누르거나 제목을 더블클릭하면 제목과 카테고리를 바꿀 수 있습니다. Enter로 저장, Esc로 취소합니다.
- 삭제할 때는 확인 창이 뜹니다.
- ◀ ▶ 버튼으로 날짜를 이동하고, "오늘" 버튼으로 돌아옵니다. 미래 날짜의 할 일은 체크할 수 없습니다.
- 카테고리 필터: 전체 / 업무 / 개인 / 공부
- 진행 막대에는 그날 전체(필터와 무관)의 완료 수, 퍼센트, 올클리어까지 남은 개수가 표시됩니다.
- 앱을 켜 둔 채 자정이 지나면 오늘 화면이 새 날짜로 넘어갑니다.

### 상점 · 구매 내역
- 포인트로 가상 기프티콘을 삽니다. 실제 결제는 없습니다.

  | 상품 | 가격 |
  |---|---|
  | 🍙 삼각김밥 | 200P |
  | ☕ 아메리카노 | 500P |
  | 🍦 아이스크림 | 800P |
  | 🍔 버거 세트 | 1,500P |
  | 🎬 영화 관람권 | 3,000P |

- 포인트가 모자라면 구매 버튼이 비활성화되고 "OOOP 부족"이 표시됩니다.
- 구매하면 `GIFT-XXXX-XXXX` 형식(대문자 + 숫자)의 가상 쿠폰 번호가 팝업으로 나옵니다.
- 구매 내역 탭에서 구매일시, 상품명, 사용 포인트, 쿠폰 번호를 최신순으로 봅니다.

### 게임 효과
- 완료하면 `+10P`, 해제하면 `-10P` 토스트가 1.5초 동안 나옵니다.
- 올클리어하면 축하 배너와 색종이가 나옵니다.
- 포인트 숫자가 바뀔 때 강조 애니메이션이 나옵니다.
- OS에서 "애니메이션 줄이기"를 켜 두면 움직임이 꺼집니다.

## 포인트 규칙

| 상황 | 포인트 |
|---|---|
| 할 일 완료 | +10P |
| 완료 해제 | −10P |
| 완료된 할 일 삭제 | −10P (받은 포인트 회수) |
| 올클리어: 그날 포인트 대상 할 일이 3개 이상이고 그날 할 일이 모두 완료 | +50P |
| 올클리어가 깨짐: 해제, 미완료 항목 추가, 완료 항목 삭제 | −50P (보너스 회수) |

- 올클리어 보너스는 날짜마다 한 번만 받습니다(`bonusDates`). 깨졌다가 다시 올클리어하면 다시 받습니다.
- 지난 날짜에도 같은 규칙이 적용됩니다.
- **기록용 할 일:** 그 날짜가 지난 뒤에 만든 할 일은 "기록용"으로 표시되고 포인트와 보너스 대상이 아닙니다. 그날 만들었거나 미리 만들어 둔 할 일은 나중에 완료해도 포인트를 받습니다.
- **포인트는 0 밑으로 내려가지 않습니다.** 회수할 포인트가 모자라면 그 동작(해제, 삭제, 추가)을 막고 안내를 보여줍니다. 회수를 건너뛰면 "해제 → 다시 완료"로 포인트를 계속 얻을 수 있기 때문입니다.

## 데이터 저장

모든 데이터는 브라우저의 `localStorage`에 저장됩니다. 서버로 전송되지 않습니다. 브라우저나 기기마다 데이터가 따로 저장되고, 브라우저 데이터를 지우면 함께 사라집니다.

| 키 | 내용 |
|---|---|
| `gameTodo.v1` | 전체 상태 (JSON) |
| `gameTodo.backup` | 읽을 수 없었던 저장값의 원본 (가장 최근 1개) |

```js
// gameTodo.v1
{
  version: 1,
  points: 0,
  todos: [{ id, title, category, date, done, createdAt, completedAt }],
  bonusDates: ["YYYY-MM-DD"],
  purchases: [{ id, itemId, name, price, code, purchasedAt }]
}
```

- `category`: `"work"` | `"personal"` | `"study"`
- `date`: 로컬 날짜 `"YYYY-MM-DD"`. UTC 기준인 `toISOString()`은 사용하지 않습니다.
- `createdAt`, `completedAt`, `purchasedAt`: 밀리초 타임스탬프. 완료 전의 `completedAt`은 `null`입니다.
- 선택한 날짜와 필터는 저장하지 않습니다. 새로고침하면 오늘, 전체로 돌아갑니다.
- 브라우저 탭을 여러 개 열어도 다른 탭에서 저장한 내용을 바로 반영해서 서로 덮어쓰지 않습니다.

### 저장값에 문제가 있을 때
- JSON이 깨졌거나, 지원하지 않는 버전이거나, 형식이 잘못된 항목이 섞여 있으면 원본을 `gameTodo.backup`에 남긴 뒤 시작합니다.
- 일부 항목만 잘못된 경우에는 정상 항목은 그대로 쓰고 잘못된 항목만 건너뜁니다.
- 백업은 개발자 도구(F12) → Application → Local Storage에서 볼 수 있습니다.

## 수정 가이드

### 설정값 바꾸기 (`app.js` 위쪽)
- `CONFIG`: 할 일당 포인트(`POINTS_PER_TODO`), 올클리어 보너스(`ALL_CLEAR_BONUS`), 보너스에 필요한 최소 개수(`MIN_TODOS_FOR_BONUS`)
- `SHOP_ITEMS`: 상점 상품 목록 (`id`, `name`, `price`, `icon`)
- `CATEGORY_LABELS`: 카테고리 표시 이름
- 색상: `style.css`의 `:root` 변수. 카테고리 색은 `--cat-*` 변수입니다.

### 코드 구조
- **포인트 계산:** `settlePoints()` 한 곳에서만 합니다. 할 일 상태를 바꾼 뒤에 호출하고, 포인트가 모자라면 `shortage`를 돌려줍니다.
- **상태 변경 함수:** `addTodo`, `setTodoDone`, `deleteTodo`는 `state`만 바꿉니다. `tryChange()`로 감싸서 실행하면, 포인트가 모자랄 때 변경 전체를 되돌립니다.
- **저장과 화면 갱신:** `commit()`이 저장과 다시 그리기를 맡습니다.
- **보안:** 사용자 입력은 항상 `textContent` 또는 `.value`로 넣습니다. `innerHTML`은 쓰지 않습니다.

### 저장 형식을 바꿀 때
1. `STATE_VERSION`을 올립니다.
2. `MIGRATIONS`에 "이전 버전 → 다음 버전" 변환 함수를 추가합니다.
   ```js
   const MIGRATIONS = {
     1: (s) => ({ ...s, version: 2, streak: 0 }),
   };
   ```
3. 필요하면 `normalizeState()`와 검사 함수(`isValidTodo` 등)를 새 형식에 맞춥니다.

변환 함수가 없으면 옛 데이터는 백업된 뒤 초기 상태로 시작합니다.
