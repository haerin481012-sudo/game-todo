# Quest To-do

할 일을 끝낼수록 펫이 자라는 게임형 할 일 관리 웹앱입니다. 오늘 할 일을 3개 이상 모두 끝내면(올클리어) 펫이 하루에 한 번 자라고, 올클리어를 이어 가면 연속 기록과 배지가 쌓입니다.

> **이전 버전(포인트·상점)에서 바뀐 점:** 할 일을 많이 만들어 포인트를 쉽게 모을 수 있는 문제가 있어서, 보상 구조를 **펫 키우기 + 연속 달성 달력**으로 바꿨습니다. 포인트·상점·구매 내역은 없어졌고, 기존 할 일과 올클리어 기록은 처음 실행할 때 자동으로 옮겨집니다([v1에서 옮기기](#v1에서-옮기기) 참고).

HTML · CSS · 순수 JavaScript만 사용합니다. 프레임워크, 빌드 도구, 외부 라이브러리, 서버, 외부 폰트가 없습니다.

## 실행 방법

`index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다. 설치나 빌드는 필요 없습니다.

- Chrome 또는 Edge를 권장합니다.
- Firefox는 설정에 따라 `file://`로 연 페이지에서 저장이 되지 않을 수 있습니다.

## 기능

### 할 일
- 제목(앞뒤 공백 제거 후 1~50자)과 카테고리(업무 / 개인 / 공부)로 추가합니다. Enter 키로도 추가됩니다.
- 체크박스로 완료하고 해제합니다. 완료한 항목은 취소선이 그어지고 목록 아래로 내려갑니다.
- 수정 버튼을 누르거나 제목을 더블클릭하면 제목과 카테고리를 바꿀 수 있습니다. Enter로 저장, Esc로 취소합니다.
- 삭제할 때는 확인 창이 뜹니다.
- ◀ ▶ 버튼으로 날짜를 이동하고, "오늘" 버튼으로 돌아옵니다. 미래 날짜의 할 일은 체크할 수 없습니다.
- 하루에 최대 20개까지 추가할 수 있습니다.
- 진행 막대 아래에 "올클리어하면 [펫이름]이 자라요" 안내가 나옵니다. 할 일이 3개 미만이면 "할 일이 3개 이상 있어야 성장해요"가 나옵니다.
- 카테고리 필터: 전체 / 업무 / 개인 / 공부
- 진행 막대에는 그날 전체(필터와 무관)의 완료 수, 퍼센트, 올클리어까지 남은 개수가 표시됩니다.
- 앱을 켜 둔 채 자정이 지나면 오늘 화면이 새 날짜로 넘어갑니다.

### 헤더
- 펫 이모지와 "🔥 N일 연속"이 항상 보이고, 누르면 내 펫 탭으로 이동합니다.

### 내 펫
- 처음 실행하면 펫 이름(1~12자)을 짓습니다. "이름 바꾸기"로 나중에 바꿀 수 있습니다.
- 단계별 모습, 이름, 단계·성장치, 기분, 다음 단계까지 남은 올클리어 일수, 받은 배지를 봅니다.

### 달력
- 월간 달력에서 올클리어한 날에 ✅ 도장이 찍힙니다. ◀ ▶로 달을 옮깁니다(이번 달 이후로는 넘어가지 않음).
- 현재 연속·최고 기록과 그달의 올클리어 일수를 보여 줍니다.
- 날짜를 누르면 그날의 할 일로 이동합니다.

### 게임 효과
- 오늘 올클리어하면 "[펫이름]이 자랐어요!" 배너와 색종이가 나옵니다.
- 단계가 오르면 진화 축하 팝업(이전 모습 ➜ 새 모습)이 뜹니다.
- 배지를 받으면 토스트로 알려 줍니다.
- 오늘 올클리어가 풀리면 "성장 -1" 토스트로 알려 줍니다.
- OS에서 "애니메이션 줄이기"를 켜 두면 움직임이 꺼집니다.

## 펫 성장 규칙

- **올클리어:** 그날 할 일이 3개 이상이고 모두 완료된 상태입니다.
- **오늘만 성장:** 오늘 날짜에 올클리어하면 `clearDates`에 오늘이 추가되고 `growth +1`. 하루에 한 번만 오릅니다.
- **오늘 올클리어가 깨지면:** 체크 해제, 미완료 항목 추가, 완료 항목 삭제로 깨지면 오늘을 빼고 `growth -1`. 다시 올클리어하면 다시 +1.
- **지난 날짜·미래 날짜:** 지난 날짜는 올클리어해도 자라지 않습니다(나중에 몰아서 체크하는 것을 막기 위해). 지난 날짜의 올클리어 기록도 바뀌지 않습니다. 미래 날짜는 체크할 수 없습니다.

| 단계 | growth | 모습 |
|---|---|---|
| 알 | 0 | 🥚 |
| 아기 | 3 | 🐣 |
| 어린이 | 7 | 🐥 |
| 어른 | 14 | 🐔 |
| 전설 | 30 | 🦚 |

| 기분 | 조건 |
|---|---|
| 😆 신남 | 오늘 올클리어 |
| 🙂 보통 | 어제 올클리어 (또는 펫을 만든 날·다음 날) |
| 😢 시무룩 | 2일 이상 올클리어 못 함 |

기분은 바뀌어도 성장 단계는 내려가지 않습니다. (오늘 올클리어를 해제해 방금 받은 +1이 취소되는 경우만 예외입니다.)

## 연속 달성 · 배지

- **현재 연속:** 오늘 올클리어했으면 오늘부터, 아직 못 했으면 어제부터 거꾸로 이어진 올클리어 일수. 오늘 아직 못 한 것만으로는 연속이 끊기지 않습니다.
- **최고 기록:** `clearDates` 전체에서 가장 길게 이어진 구간의 일수.
- **배지:** 최고 기록이 기준에 닿으면 받습니다. 연속이 끊겨도 한 번 받은 배지는 `badges`에 남습니다.

| 배지 | 조건 |
|---|---|
| 🔥 불꽃 시작 | 연속 3일 |
| 🏆 일주일 챔피언 | 연속 7일 |
| 💎 꾸준함의 달인 | 연속 14일 |
| 👑 한 달의 전설 | 연속 30일 |

v1에서 옮겨 온 기록으로 이미 조건을 채운 배지는 앱을 시작할 때 조용히 지급됩니다.

## 데이터 저장

모든 데이터는 브라우저의 `localStorage`에 저장됩니다. 서버로 전송되지 않습니다. 브라우저나 기기마다 데이터가 따로 저장되고, 브라우저 데이터를 지우면 함께 사라집니다.

| 키 | 내용 |
|---|---|
| `gameTodo.v2` | 전체 상태 (JSON) |
| `gameTodo.backup` | 읽을 수 없었던 v2 저장값의 원본 (가장 최근 1개) |
| `gameTodo.v1` | 이전 버전(포인트·상점) 데이터. 읽기만 하고 지우지 않습니다 |
| `gameTodo.v1.backup` | v1 → v2 변환 직전에 복사해 둔 v1 원본 |

```js
// gameTodo.v2
{
  version: 2,
  todos: [{ id, title, category, date, done, createdAt, completedAt }],
  clearDates: ["YYYY-MM-DD"],                     // 올클리어한 날짜 (오름차순)
  pet: { name: "", growth: 0, createdAt: "YYYY-MM-DD" },
  badges: []                                      // 받은 배지 id
}
```

- `category`: `"work"` | `"personal"` | `"study"`
- `date`, `pet.createdAt`: 로컬 날짜 `"YYYY-MM-DD"`. UTC 기준인 `toISOString()`은 사용하지 않습니다.
- `createdAt`, `completedAt`: 밀리초 타임스탬프. 완료 전의 `completedAt`은 `null`입니다.
- 선택한 날짜와 필터는 저장하지 않습니다. 새로고침하면 오늘, 전체로 돌아갑니다.
- 브라우저 탭을 여러 개 열어도 다른 탭에서 저장한 내용을 바로 반영해서 서로 덮어쓰지 않습니다.

### v1에서 옮기기
앱을 시작할 때 `gameTodo.v2`가 없고 `gameTodo.v1`이 있으면 한 번 변환합니다.

1. v1 원본 문자열을 `gameTodo.v1.backup`에 그대로 복사합니다. `gameTodo.v1`은 지우지 않습니다.
2. `todos`는 그대로 옮깁니다(형식이 잘못된 항목만 제외).
3. `bonusDates`를 `clearDates`로 옮기고, `pet.growth`는 `clearDates` 개수로 시작합니다.
4. `points`, `purchases`는 옮기지 않습니다.
5. 결과를 바로 `gameTodo.v2`에 저장합니다. 다음부터는 v2만 읽습니다.

v1 JSON이 깨졌거나 v1 형식이 아니면 빈 v2로 시작합니다. 이때도 원본은 백업과 v1 키에 남아 있습니다.

### 저장값에 문제가 있을 때
- (v2) JSON이 깨졌거나, 지원하지 않는 버전이거나, 형식이 잘못된 항목이 섞여 있으면 원본을 `gameTodo.backup`에 남긴 뒤 시작합니다.
- 일부 항목만 잘못된 경우에는 정상 항목은 그대로 쓰고 잘못된 항목만 건너뜁니다.
- 모든 localStorage 접근은 try/catch로 감싸져 있어서, 저장소가 막혀 있어도 오류 없이 빈 상태로 시작합니다.
- 백업은 개발자 도구(F12) → Application → Local Storage에서 볼 수 있습니다.

## 수정 가이드

### 설정값 바꾸기 (`app.js` 위쪽)
- `CONFIG`: 올클리어 최소 할 일 수(`MIN_TODOS_FOR_CLEAR`), 하루 최대 할 일 수(`MAX_TODOS_PER_DAY`), 펫 이름 최대 길이(`PET_NAME_MAX_LENGTH`)
- `PET_STAGES`: 성장 단계 (`min`, `name`, `icon`)
- `PET_MOODS`: 기분 표시 (`label`, `icon`, `note`)
- `STREAK_BADGES` (`streak.js`): 연속 달성 배지 (`id`, `days`, `name`, `icon`)
- `CATEGORY_LABELS`: 카테고리 표시 이름
- 색상: `style.css`의 `:root` 변수. 카테고리 색은 `--cat-*` 변수입니다.

### 코드 구조
- **저장소 접근:** `readStorage()` / `writeStorage()`만 사용합니다. 둘 다 예외를 잡습니다.
- **불러오기:** `loadState()` → (v2 있음) `migrateState()` → `normalizeState()` / (v1만 있음) `migrateFromV1()` → `convertV1ToV2()`
- **펫 성장:** `updateGrowth()` 한 곳에서만 `clearDates`와 `pet.growth`를 바꿉니다. 할 일 상태를 바꾼 뒤에 호출하고, 오늘 날짜가 아니면 아무것도 바꾸지 않습니다. 단계는 `getPetStage()`, 기분은 `getPetMood()`가 계산합니다.
- **연속 달성:** `streak.js`의 `getCurrentStreak(clearDates, today)`, `getBestStreak(clearDates)`, `mergeBadges(owned, best)`는 날짜 문자열만 받는 순수 함수입니다. 올클리어가 새로 추가될 때 `syncBadges()`가 배지를 더합니다.
- **테스트:** `tests/streak.test.html`을 브라우저로 열면 연속 달성 계산 테스트 결과가 화면과 콘솔(F12)에 나옵니다.
- **상태 변경 함수:** `addTodo`, `setTodoDone`, `deleteTodo`는 `state`만 바꾸고 `updateGrowth()` 결과를 돌려줍니다. `finishChange()`가 저장(`commit()`)과 효과 표시를 마무리합니다.
- **보안:** 사용자 입력은 항상 `textContent` 또는 `.value`로 넣습니다. `innerHTML`은 쓰지 않습니다.

### 저장 형식을 바꿀 때
1. `STATE_VERSION`을 올립니다.
2. `MIGRATIONS`에 "이전 버전 → 다음 버전" 변환 함수를 추가합니다.
   ```js
   const MIGRATIONS = {
     2: (s) => ({ ...s, version: 3, streak: 0 }),
   };
   ```
3. 필요하면 `normalizeState()`와 검사 함수(`isValidTodo` 등)를 새 형식에 맞춥니다.

같은 키 안의 버전 변환은 `MIGRATIONS`가 맡습니다. 변환 함수가 없으면 옛 데이터는 백업된 뒤 초기 상태로 시작합니다. (v1 → v2는 저장 키까지 바뀌므로 `migrateFromV1()`이 따로 처리합니다.)
